# 멘트윈 백업·복구 안내 (2026-10-31)

## 지금 상태
- 코드에는 백업 기능이 없었음 → 이번에 **복구 리허설 스크립트** 추가 (`scripts/restore-drill.sh`)
- Render DB의 백업은 **요금제에 따라 다름** (Render 공식 문서 기준):
  - 무료(Free) DB: Render가 백업을 만들지 않음. 시점 복구(PITR)도 없음.
  - 유료 DB: Hobby 작업공간은 최근 3일, Pro 이상은 최근 7일 시점 복구.
  - 'Create export'(내려받는 백업 파일)는 만든 뒤 7일만 Render에 보관됨 → **내려받아 따로 보관해야 함**
- 위너스학원 운영 DB가 무료인지 유료인지는 **확인 불가** (Render 화면에서 원장님 확인 필요)

## 원장님 확인 (5분)
1. https://dashboard.render.com 로그인
2. 왼쪽 목록에서 **PostgreSQL**(데이터베이스) 클릭
3. 화면 위쪽 **Instance Type**(요금제)이 `Free`인지 확인
   - `Free`라면: 백업이 없습니다. 실제 학생 시범 운영 전에 유료(Basic 이상)로 바꾸는 것을 권합니다. 결제가 필요하니 승인 후 진행합니다.
4. 왼쪽 메뉴 **Recovery** 클릭 → **Create export** → 몇 분 뒤 목록에 생긴 파일 **Download**
5. 내려받은 파일(`.dir.tar.gz`)을 **구글 드라이브의 비공개 폴더**에 보관 (학생 정보가 들어 있으니 공유 금지)

주 1회(예: 매주 월요일) 4~5번을 반복합니다. 자동화는 사진 저장소(R2) 승인 후 같은 곳에 자동 보관하도록 붙일 수 있습니다.

## 암호화 키 따로 보관 (가장 중요)
- 학생 실명·학부모 번호는 DB 안에서 **암호화**되어 있습니다. 풀려면 Render Environment의 `PII_ENC_KEY`, `PII_HASH_KEY`가 필요합니다.
- 키를 잃으면 백업이 있어도 학부모 번호를 되살릴 수 없습니다. (복구 리허설에서 키가 다르면 복호화가 실패하는 것을 확인함)
- 보관 방법: Render → 서비스 → **Environment** → 두 값을 복사해 **비밀번호 관리 앱**(예: 휴대폰 기본 비밀번호 관리자) 또는 종이에 적어 금고에 보관.
- 채팅·카톡·메일에 붙여 넣지 마세요.

## 복구 리허설 (개발 쪽에서 실행)
```
bash scripts/restore-drill.sh <원본 DB 주소> <새 빈 DB 이름> [Render export 파일]
```
- 원본 DB에는 읽기만 하고, 복구는 새로 만든 빈 DB에만 합니다.
- 결과: 표 20개 행 수가 원본과 같으면 성공.
- 2026-10-31 시험 DB 리허설 결과: 20개 표 모두 일치, 올바른 키로 학생 실명 복호화 성공, 다른 키로는 실패(정상).
- 운영 DB로 하는 첫 리허설은 원장님 승인 후, Render export 파일로 진행합니다.
