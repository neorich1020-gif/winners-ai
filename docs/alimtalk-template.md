# 카카오 알림톡 템플릿 2종 (검수 신청용)

매주 학부모 1명에게는 아래 둘 중 **한 건만** 갑니다.
원장님이 승인한 상담글이 있으면 ②, 없으면 ①(학원 설정에서 ① 자동 발송을 끌 수 있음).

---

## ① 주간 학습 리포트 (자동 통계)
- 환경변수: `KAKAO_TEMPLATE_WEEKLY`
- 메시지 유형: 기본형 (정보성) · 카테고리: 교육 > 학습 안내

```
[#{학원명}] #{학생명} 학생 주간 학습 리포트

■ 이번 주 학습일: #{학습일수}일
■ 질문한 문제: #{질문수}개 (스스로 해결 #{해결률})
■ 공부한 단원: #{학습단원}
■ 보완이 필요한 단원: #{보완단원}
■ 원장 코멘트: #{원장코멘트}

※ 본 메시지는 학습 리포트 수신에 동의하신 학부모님께 매주 발송됩니다.
```

---

## ② 주간 상담 (원장님 승인 상담글)
- 환경변수: `KAKAO_TEMPLATE_COUNSEL`
- 메시지 유형: 기본형 (정보성) · 카테고리: 교육 > 학습 안내

### 방식 A — 본문 그대로 (COUNSEL_MODE=inline, 기본)
```
[#{학원명}] #{학생명} 학생 주간 상담 안내

#{상담내용}

※ 본 메시지는 상담 안내 수신에 동의하신 학부모님께 발송됩니다.
```
- `#{상담내용}` = 원장님이 승인한 본문 + 서명. 본문은 800자 이하로 제한(알림톡 전체 1,000자 한도).
- **검수 주의**: 본문 대부분이 변수인 템플릿은 반려될 수 있습니다. 검수 신청 시 "학원 원장이 매주 학생별로 작성·승인하는 학습 상담 안내이며 광고 내용은 포함하지 않음"이라고 사용 목적을 적고, 실제 예시 문안을 함께 첨부하세요.
- 반려되면 방식 B로 바꾸면 됩니다 (`COUNSEL_MODE=link`, 코드 수정 불필요).

### 방식 B — 안내 + 버튼 (COUNSEL_MODE=link)
```
[#{학원명}] #{학생명} 학생 주간 상담 안내

#{원장명} 원장님이 이번 주 #{학생명} 학생의 학습 상담글을 보내셨습니다.
아래 버튼을 눌러 전체 내용을 확인해 주세요.

※ 링크는 30일 동안 열람할 수 있습니다.
```
- 버튼: 웹링크(WL) "상담글 전체 보기" → `https://<서비스주소>/letter/#{토큰}` 형태로 등록 (발송대행사 안내에 맞춰 링크 변수 방식 확인)
- 링크는 학부모별로 다른 48자리 무작위 토큰, 30일 후 만료, 첫 열람 시각이 기록됩니다.

## 공통 검수 통과 팁
- 알림톡은 '정보성' 메시지만 가능합니다. 반 모집·할인·이벤트 문구가 들어가면 반려되거나 이후 발송이 차단될 수 있습니다. 상담글 생성 AI는 이런 표현을 쓰지 않도록 되어 있고, 원장님이 직접 넣으면 화면에 경고가 뜹니다.
- 변수(#{...})는 코드(`weeklyReport.js`)와 글자 하나까지 같아야 발송됩니다.
- 발송 전 준비: ① 카카오톡 채널 개설 → ② 비즈니스 채널 인증 → ③ 발송대행사(솔라피 등)에 채널 연동 → ④ 템플릿 2종 검수(보통 1~3영업일) → ⑤ 대체문자 발신번호 등록
