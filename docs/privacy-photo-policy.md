## 2. 보호자 동의

| 동의 항목 | 필수/선택 | 지금 |
|---|---|---|
| 개인정보 수집·이용 (만 14세 미만은 법정대리인 동의) | 필수 | 기록 칸 있음, **이용 전 확인은 안 함** |
| AI 처리 및 국외 이전 (Anthropic, 미국) | 필수 (AI 질문 이용 시) | 기록 칸 있음, 확인 안 함 |
| 숙제 사진 촬영·보관 (90일, Cloudflare R2) | 필수 (사진 인증 이용 시) | **신규 항목** |
| 주간 리포트 알림톡 수신 | 선택 | 구현됨 (동의 없으면 발송 안 함) |

**제안 (2주차와 함께, 원장님 승인 후)**
1. 원장 화면 학생 목록에 '보호자 동의' 표시(완료/미완료).
2. 학원 설정에 **"동의 완료 학생만 이용"** 스위치. 처음에는 꺼 두고, 위너스학원 학생 동의서를 다 받은 뒤 켭니다. → 지금 쓰는 학생이 갑자기 막히지 않게.
3. 스위치가 켜진 학원에서 동의 미완료 학생은 로그인 후 "보호자 동의가 필요해요. 선생님께 말해 주세요" 안내만 보임.
4. 동의서 양식(종이/온라인)은 GPT 쪽에서 쓰기로 한 초안을 이 표 항목에 맞춰 정리.

- 처리 목적: AI 학습 도움, 숙제 확인, 학부모 학습 안내
- 처리 항목: 학생 별명·출석번호·(암호화) 실명, 질문 내용·사진, 숙제 사진, 학부모 휴대폰(암호화)
- 보관 기간: 위 1번 표
- **처리 위탁·국외 이전**: Anthropic(AI, 미국), Render(서버·DB, 미국), Cloudflare(R2 사진 저장, 위치 선택 가능), 솔라피(알림톡, 국내), 토스페이먼츠(결제, 국내) — 이전 항목·목적·보관 기간 명시
- 만 14세 미만 법정대리인 동의 방법
- 정보주체 권리(열람·정정·삭제·처리정지)와 요청 방법
- 개인정보 보호책임자(원장님 또는 지정자) 연락처
- 안전성 확보 조치: 암호화 저장, 학원별 데이터 분리, 접근 기록, 사진 임시 주소

## 4. Cloudflare R2 (사진 저장소) — 가입 절차와 예상 비용

**비용** (Cloudflare 공식 요금표, 2026-10-31 확인)
- 저장: GB당 월 $0.015 · 업로드(Class A) 100만 건당 $4.50 · 보기(Class B) 100만 건당 $0.36 · 내보내기(egress) 무료
- **무료 범위(매월)**: 저장 10GB, 업로드 100만 건, 보기 1,000만 건

| 상황 | 계산 | 예상 비용 |
|---|---|---|
| 시범 (중2 수학 1반 20명, 하루 2장, 장당 약 0.4MB, 90일 보관) | 월 약 0.5GB 쌓임 → 90일 뒤 약 1.5GB 유지, 업로드 월 1,200건 | **0원** (무료 범위 안) |
| 학원 10곳 × 30명 | 약 22GB 유지 → 무료 10GB 초과분 12GB × $0.015 | 월 약 $0.18 (약 250원) |

**가입 절차** (원장님 승인 후 함께 진행)
1. https://dash.cloudflare.com 에서 이메일로 계정 만들기 (학원 대표 이메일 권장)
2. 왼쪽 메뉴 **R2 Object Storage** → 사용 시작. 이때 결제 수단(카드) 등록을 요구할 수 있습니다 — 무료 범위 안이면 청구 0원. **카드 번호는 채팅에 쓰지 마세요.**
3. 버킷 만들기: 이름 `mentwin-homework`, 위치 자동(또는 아시아 태평양). **공개 접근(Public access) 켜지 않음**
4. 버킷 설정 → 객체 수명 주기(Object lifecycle) → "90일 후 삭제" 규칙 추가
5. **API 토큰 만들기**: 이 버킷 하나에만 '객체 읽기·쓰기' 권한
6. 받은 값(계정 ID, 액세스 키, 비밀 키)은 **Render Environment에만** 입력 — 채팅에 붙여 넣지 않음
