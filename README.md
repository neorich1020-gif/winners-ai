# AI 원장쌤 — 학원 B2B AI 페르소나 서비스 MVP

학생은 QR로 접속해(홈 화면에 앱처럼 추가 가능) 글이나 **문제집 사진**으로 질문하고 **원장님 말투로 단계별 힌트**를 받고, 원장님은 대시보드에서 말투·교재·질문을 관리하며,
학부모는 **매주 금요일 오후 6시(학원별 변경 가능)** 카카오 알림톡으로 1:1 메시지를 받습니다.
원장님이 키워드만 적으면 AI가 원장님 말투로 **주간 상담글**을 써 주고, 원장님이 고쳐서 승인한 글만 발송됩니다.
승인된 상담글이 없는 학생은 AI 질문창 통계로 만든 자동 리포트가 대신 갑니다(끌 수 있음).

## 폴더 구조
```

├─ db/schema.sql              DB 테이블 + 학원별 데이터 분리(RLS) + QR·상담글 링크 조회 함수
├─ db/functions.sql           로그인 전 조회 함수 2개 (QR 반 확인, 상담글 링크)
├─ db/setup.js               ★ 서버 시작 때 자동 실행: 테이블 생성·학원 분리 설정·체험 학생 생성 (멱등)
├─ db/roles.sql               (선택) DB 계정 2개 방식 — Render처럼 계정 1개면 불필요
├─ render.yaml                ★ Render Blueprint: 서버+DB 한 번에 생성, 보안 키 자동 생성
├─ src/server.js              웹 서버 + 스케줄러 3종(주간 리포트 / 정기결제 / 대화 자동 파기)
├─ src/ai/prompt.js           ★ 원장님 페르소나·힌트 4단계·학습 외 차단 프롬프트, 입력/출력 안전검사
├─ src/ai/tutor.js            학생 질문 1건 처리 (Claude API 호출)
├─ src/ai/counsel.js          ★ 원장님 말투 주간 상담글 생성 프롬프트 + 사후 점검(홍보·진단·지어낸 점수 경고)

├─ src/routes/director.js     원장: 말투·교재 세팅, 반/학생/학부모 등록, 모니터링
├─ src/routes/counsel.js      ★ 주간 상담·리포트 관리: 학생 표 입력, 상담글 생성·수정·승인, 일괄 처리
├─ src/routes/signup.js       ★ 공개: 요금제 목록(GET /api/plans), 원장님 가입·14일 체험·Zoom 세팅 신청(POST /api/signup)
├─ src/lib/plans.js           ★ 요금제 3종 표시·정원 판단·라이트 사진 월 100회 차감
├─ src/routes/billing.js      토스페이먼츠 카드 등록·월 자동결제·해지
├─ src/jobs/weeklyReport.js   ★ 금요일 학부모 알림톡 발송 (승인 상담글 우선 → 없으면 자동 통계, 중복 방지·재시도·동의 확인)
├─ public/student.html, student.js  ★ 실제 학생 질문창 (번호+PIN 로그인, 질문, 힌트, 📷 사진 업로드)
├─ public/sw.js, offline.html, icons/  PWA: 서비스 워커, 오프라인 안내, 앱 아이콘
```

## 배포 (코딩 없이)
Render **New → Blueprint**로 이 저장소를 연결하면 끝납니다. 자세한 클릭 순서는 `docs/deploy.md`.

## 실행 순서 (개발자에게 전달용)
1. Node.js 20 이상, PostgreSQL 준비
2. `.env.example` → `.env` 복사 후 값 채우기 (`openssl rand -base64 32` 등으로 보안 키 생성)
3. `npm install` → `npm run db:setup` (테이블·학원 분리 자동) — 계정 2개 방식이면 `npm run db:init` 후 `db/roles.sql`
4. `npm run report:dry-run` 으로 알림톡 실제 발송 없이 리포트 미리보기
5. `npm start` → `/director`(원장), `/s/<QR토큰>`(학생)
6. 실서비스 전 `DRY_RUN=0`, 토스 키를 `live_`로 교체

## 요금제 (DB `plans` 표가 기준, 결제 금액도 여기서)
| 플랜 | 월 요금 | 학생 수 | 사진 질문 | 추가 기능 |
| --- | --- | --- | --- | --- |
| 라이트 `lite` (기본) | 49,000원 | 30명 이하 | 학원 전체 월 100회 | 텍스트 무제한, 원장 말투 주간 상담글, 알림톡 |
| 스탠다드 `standard` | 69,000원 (정가 99,000원, 출시 기념 평생 할인) | 60명 이하 | 무제한 | 시험기간 모드·음성 리포트·상담생 체험 모드 *(곧 제공)* |
| 프리미엄 `premium` | 119,000원 | 제한 없음 (다과목) | 무제한 | 강사별 멀티 페르소나·블로그/당근 홍보글 *(곧 제공)* |

- 스탠다드를 고르는 순간 69,000원이 `academies.price_locked_krw`에 저장돼, 이후 정가가 바뀌어도 그 학원은 같은 금액으로 청구
- 라이트 사진 질문은 `monthly_usage`에서 한 장씩 차감(매월 1일 초기화). 101번째는 402 `PHOTO_QUOTA` → 학생 화면에 "글로 질문" + 스탠다드 안내 팝업, 원장 화면 상단에 소진 배너. 글 질문은 계속 무제한
- 정원 도달·초과 시 상단 배너와 다음 플랜 추천. 학생 수가 더 작은 플랜으로는 내릴 수 없음(퇴원 처리 후 가능)
- 기능 중 '곧 제공'(`ready:false`)은 아직 개발 전 → 화면에 그대로 표시해 없는 기능을 파는 일이 없게 함

## 검증 결과 (2026-10-05)
실제 PostgreSQL 16에 스키마를 적용하고 서버를 띄워 확인했습니다. AI 응답만 가짜, 알림톡은 DRY_RUN.
- 서버·DB 통합 테스트 39개 통과: 표 입력 → 생성 → 수정 → 승인 → 재승인, 일괄 생성·승인, 800자 제한,
  다른 학원 접근 차단, 학생 질문창, 금요일 발송(승인 상담글 / 자동 리포트 대체 / 동의 없는 학부모 제외 / 중복 방지), 링크 열람
- 사진 질문·요금제·PWA를 더한 뒤 재검증: 서버·DB 통합 테스트 **68개 통과** (사진이 Claude에 image 블록으로 전달, 후속 질문에도 사진 유지, 가짜·4MB 초과 사진 거절, 30/31명 뱃지, 반별 앱 정보·서비스 워커·아이콘 제공)
- 배포 준비 후 재검증(2026-10-06): Render와 같은 '관리자 권한 없는 DB 계정 1개'에서 자동 설정 2회 연속 성공, 통합 90개 통과(계정 2개 방식도 90개), 첫 배포 흉내(테이블 생성→체험 학생→서버 시작→로그인) 확인
- 요금제 3종·가입·학생 화면 개편 후 재검증: **서버·DB 90개, 학생 화면 21개, 시연판 59개 모두 통과**
  (가격 고정 후 정가 인상에도 69,000원 유지, 100번째 사진 성공·101번째 거절, 소진 후 글 질문 가능, 스탠다드로 올리면 즉시 사진 재개, 61명→라이트 변경 차단, 가입 중복 이메일 차단)
- 실제 카카오 발송과 실제 Claude 응답은 키·템플릿 승인 후 원장님 번호로 1건 시험 발송 필요

## 주간 상담글 API 요약 (`/api/director/counsel`)
| 동작 | 호출 |
| --- | --- |
| 이번 주 학생 표 | `GET /` |
| 한 줄 저장 (과목·학습 상태·태도) | `PUT /:studentId` |
| 상담글 생성 | `POST /:studentId/generate` |
| 직접 수정 | `PUT /:studentId/text` (승인돼 있었다면 다시 승인 필요) |
| 승인 / 취소 | `POST /:studentId/approve`, `/unapprove` |
| 일괄 생성 / 일괄 승인 | `POST /bulk/generate`, `/bulk/approve` |

## 아직 MVP에 없는 것 (2단계)
- 실제 원장 화면 — `public/prototype.html` 시연판 디자인을 보고 이식 (API는 모두 준비됨, 지금 `/director`는 시연판으로 연결). 학생 화면은 완성
- 원장 회원가입/비밀번호 재설정, 강사 계정 초대
- 학부모 수신동의 온라인 페이지 (현재는 원장님이 종이 동의서 확인 후 체크)
